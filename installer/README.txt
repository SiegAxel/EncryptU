EncryptU - Secure Password Manager
=====================================

Thank you for installing EncryptU!

GETTING STARTED:
1. Launch EncryptU from your desktop or Start Menu
2. Create an account or login with existing credentials  
3. Start managing your passwords securely

FEATURES:
• End-to-end encryption for all your passwords
• Cross-device synchronization via secure API
• Modern, intuitive interface
• Secure password generation
• Safe storage in the cloud

FIRST STEPS:
1. Create your account with email and password
2. Set up your master key (DON'T FORGET THIS!)
3. Start adding your passwords securely

IMPORTANT:
- Your master key is the only way to decrypt your data
- Keep it safe and NEVER share it
- If you lose it, you cannot recover your passwords
